Clojure dataframes · v2.1.3

Process data that doesn’t fit in memory.

Clojask reads a large CSV file in chunks, runs your filters, transformations, group-bys and joins on all CPU cores, and writes the result straight to a new file. You write ordinary Clojure functions; Clojask handles the streaming.

salaries.clj
(require '[clojask.dataframe :as ck])

;; 1. point at a file (nothing is read yet)
(def df (ck/dataframe "employees.csv"))

;; 2. describe the work
(ck/set-type df "Salary" "int")
(ck/filter df "Salary" #(< % 10000))
(ck/operate df #(quot % 10) "Salary" "Bonus")

;; 3. run it: 4 worker threads, file to file
(ck/compute df 4 "with-bonus.csv")

Why Clojask?

Larger than memory

Rows stream from disk in small batches, so memory use doesn’t grow with the size of the file.

Parallel by default

Up to eight worker threads process batches at once, and the output keeps the input’s row order.

Lazy pipeline

Steps are recorded, checked on a sample, and run together in a single pass over the file.

Plain Clojure functions

Filters, transformations and aggregations are ordinary functions on ordinary Java and Clojure values.

Relational operations

Filter, group-by, aggregate, inner, left, right and outer joins, plus rolling joins for time series.

File in, file out

Reads CSV, TSV and other text files (and Excel through clojask-io), and writes text or .xlsx.

How it works, in three steps

  1. Point at a file(ck/dataframe "big.csv") reads only the column names.
  2. Describe the workset-type, filter, operate, group-by, aggregate or a join add steps to the recipe.
  3. Compute(ck/compute df 8 "out.csv") streams the file through every step once, on 8 threads.

Core Concepts explains what happens inside compute.

Is Clojask the right tool?

A good fit

  • CSV files too large to load, or close to the size of your RAM
  • Batch jobs: clean, filter, enrich, group and join, then write a file
  • Logic you want to write as plain Clojure functions
  • One machine, no cluster to run

Look elsewhere when

  • The data fits in memory and you want to explore it interactively: try tech.ml.dataset or Datajure
  • You need to sort a large result, or look up individual rows
  • You run on Windows (Clojask supports macOS and Linux)
