Process data that doesn’t fit in memory.

Clojask reads a large CSV file in chunks, runs your filters, transformations, group-bys and joins on all CPU cores, and writes the result straight to a new file. You write ordinary Clojure functions; Clojask handles the streaming.

salaries.clj
(require '[clojask.dataframe :as ck])

;; 1. point at a file (nothing is read yet)
(def df (ck/dataframe "employees.csv"))

;; 2. describe the work
(ck/set-type df "Salary" "int")
(ck/filter df "Salary" #(< % 10000))
(ck/operate df #(quot % 10) "Salary" "Bonus")

;; 3. run it: 4 worker threads, file to file
(ck/compute df 4 "with-bonus.csv")
