The project

Clojask is an open-source Clojure library developed at HKU Business School, as part of clojure-finance. It aims to make data that doesn't fit in memory as easy to work with as a small dataframe, on a single machine.

It is made of three parts:

  • clojask: the dataframe API and the engine that runs it.
  • clojask-io: reading and writing text and Excel files, installed together with clojask.
  • clojask-examples: runnable example programs, shown on the Examples page.

The faster time in each comparable pair is in bold. * Dask could not finish any operation on 80M rows within 7 hours. The rolling join was not benchmarked for Dask.

How to read these numbers:

  • Clojask was faster at element-wise operations, filtering and whole-file aggregation, and it still finished at 80M rows, where Dask did not.
  • Dask was faster at group-by and joins on the smaller files.
  • Every time includes loading the libraries, reading the CSV file, and writing the result to a single CSV file.

The benchmarks ran on macOS (Darwin 20.4.0) on an x86_64 machine with 8 GB of RAM. The code is in the clojask repository:

Design history

Up to version 2.0.x, Clojask ran its pipelines on Onyx, a distributed computation framework, inside one process. Version 2.1.0 replaced Onyx with a small thread pool of its own: one thread reads the input in batches, a pool of worker threads runs the operations, and the calling thread writes the output. That removed a large dependency and the JVM flags it needed, and made every operation tested so far faster. Core Concepts describes the current design.
